# Support

For setup questions and troubleshooting, read `使用說明.txt` and `docs/TROUBLESHOOTING.md` first.

When opening a support Issue, include:

- application version or commit;
- Windows and OBS versions;
- exact DJI/Osmo device names shown by the launcher;
- camera count and USB connection layout;
- node port and `/status` output with IP addresses redacted if necessary;
- whether OBS uses `/obs.mjpg`, `/obs`, NDI, or a direct Video Capture Device;
- the smallest reliable reproduction sequence.

This is a volunteer community project. Response times are not guaranteed.
